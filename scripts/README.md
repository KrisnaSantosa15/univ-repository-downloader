# Scripts Directory

This directory contains utility scripts for the UPI Repository Downloader project.

## Scripts

### `check_dependencies.py`
Checks if all required Python packages are installed. Run this before using the main application.

**Usage:**
```bash
python scripts\check_dependencies.py
```

## Legacy

The `legacy/` folder contains older versions of the code for reference purposes only.

### `legacy/skripsi-downloader.py`
Original monolithic version of the downloader before the modular refactoring. Kept for historical reference.

**Note:** Use the main application (`python main.py`) instead of legacy scripts.
